# 구현 결정

- 2026-10-31: 상세설계서 v1.0과 실행프롬프트 v1.0을 기준으로 신규 React+TypeScript+Vite 정적 앱을 생성했다.
- 실제 악기 모델 미정. 기본은 C4~C5 학습용 확대, 실제 음역은 null.
- 출시용 녹음 음원을 확보하지 않았으므로 학습용 합성음임을 UI에 표시한다.
- 32종 자체 그림 SVG를 참고/설명 자료로 보존했다. 동적 손 리그는 별도로 제작했다.
- 앱/수업 데이터는 프런트엔드 전용. 마이크·계정·서버·학생 이름을 사용하지 않는다.
- sourceIds, 두 연습곡, 운지·리듬·퀴즈는 설계서의 값을 사용한다.
- 자동 손자리 이동은 음악 tick에서 movement progress를 계산하며 별도 손 타이머를 사용하지 않는다.
- 개발 중 유효한 기존 학습 범위 안의 C5가 불필요하게 높은 옥타브로 이동하는 문제를 수정했다.
- 교실·실제 악기·실제 스피커 청취 검수는 코드/브라우저 검증과 분리한다. 비공개 기술 빌드 배포와 현장 출시 승인을 구별한다.
- 오프라인은 HTTPS/지원 브라우저에서 사용하며, HTTP 미리보기에서 지원되지 않으면 정확한 안내를 표시한다.
