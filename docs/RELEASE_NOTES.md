# 멜로디카 클래스 1.0.0

비공개 교사용 기술 빌드. 앱·콘텐츠·저장 스키마 1.0.0.

6단원·12차시, 도/파 손자리, 분리 관절 손 리그, 오선/건반/계이름, 숫자키/포인터, 완전무음, 시범/함께연주, 예비박/구간반복/BPM, 호흡/텅잉/쉼/붙임줄, 단계 손자리이동, 곡2·리듬3·퀴즈12, 학급관찰, 설정백업, 필수파일 전체해시 검증 오프라인을 구현했다.

기본 음색은 학습용 합성음이다. 실제 모델을 추정하지 않는다. 검토하지 않은 응용곡 전체악보·미검토 운지·마이크 채점·개인계정은 포함하지 않는다.

검증: npm run build + npm test(13PASS), 핵심 브라우저 흐름. 실제 악기·청취·출력지연·교실40분 시험은 pending. HTTP 미리보기에는 오프라인 지원 제한이 있으며 HTTPS 지원 브라우저에서 준비한다.

롤백: 같은 Site의 이전 검증 버전이 생기면 그 app/content 조합으로 돌아간다. 최초 버전이므로 이전 배포의 실제 롤백 실행은 해당 없음이다. 저장 스키마를 임의로 삭제하지 않는다.
