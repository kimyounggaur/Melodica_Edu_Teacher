# 멜로디카·오른손 시각 리마스터 1.1

## 원본과 재구성 범위

사용자가 제공한 피아노 코드 운지 자료의 Illustrator 원본과 PNG를 시각 참고로 검토했다. 대표 AI는 PDF 호환 Illustrator 28.2 파일이며, 상위 레이어 2개와 벡터 drawing 857개를 포함했다. 분석 과정에서 오른손 8개 포즈의 외곽·손톱·관절선 107개 경로를 추출하여 손의 실루엣과 디테일을 확인했다.

원본은 한 포즈마다 손 전체 외곽과 내부 선으로 이루어져 있다. 앱의 단선율 손자리와 관절 움직임에 맞추기 위해 손목·손등·엄지·네 손가락을 분리된 SVG 구조로 재구성한다. 피아노 화음의 손 벌림이나 왼손 운지를 멜로디카 오른손 운지로 그대로 사용하지 않는다. 전체 AI와 코드표 원본은 앱 자산에 포함하지 않는다.

## 구현

- `MelodicaShellV2`: 성형 본체, 키베드, 공기 연결부, 그릴, 배기 버튼, 테두리 반사광과 체결부.
- `RightHandRigV2`: 오른손 손목·손등과 손가락별 관절·손톱·접촉 그림자.
- 건반: 아이보리와 검은 건반의 깊이, 앞면, 반사광, 선택/눌림 색과 일관된 눌림 이동.
- 도 자리/파 자리 손가락 매핑은 도메인 기준을 그대로 따른다. 실제 악기 음역이나 모델을 추정하지 않는다.
- 손자리 이동은 기존 음악 타임라인의 release/lift/translate/settle/ready 단계와 연결하며, 동작 줄이기 설정을 존중한다.
- 누름·해제 시 외곽선·관절·손톱을 같은 96ms 시각 진행도로 갱신하고, 빠른 입력 반전과 이동 시작 시 예약 프레임을 정리한다.
- `손모양 전체`와 `건반 확대`를 전환할 수 있다. 전체 보기에서는 손목까지 보여 주며, 확대 보기에서는 건반과 손끝을 크게 보여 준다.

## 검증 범위

타입 검사와 프로덕션 빌드가 통과했다. 기존 음악/오프라인 검증 13개와 손끝 위치·투영 길이 검증 2개, 총 15개 자동 검증이 통과했다. 손 1~5 및 정지 상태에서 관절 좌표가 유한하고, 투영 마디 길이가 해부학적 길이를 넘지 않으며, 손끝이 지정 건반 중심에 맞고 손가락이 뒤로 접히지 않는 것을 검증했다.

브라우저에서 전체/확대 보기, 도 자리/파 자리, 높은 도=파 자리의 손5, 계이름 표시 위치, 이동 단계, 이동 완료 후 위치, 움직임 줄이기(transition 0s), 무음 손연습의 재생 흐름을 확인했다. 실제 악기의 손 모양과 연주 자세에 대한 음악 교사 실기 검수는 별도 대상이다.
